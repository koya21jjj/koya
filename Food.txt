ช่วยวางแผน Landing Page สำหรับคนที่ไม่เคยเขียนโค้ดมาก่อน

ขอ:
1. เป้าหมายของเว็บไซต์
2. กลุ่มผู้เข้าชม
3. Sections ที่ควรมี เรียงตามลำดับ
4. ข้อความสำคัญของแต่ละ Section
5. สิ่งที่อยากให้ผู้เข้าชมทำ เช่น ติดต่อเรา หรือขอใบเสนอราคา

ยังไม่ต้องเขียนโค้ด

จากแผน Landing Page ที่เราวางไว้

ช่วยแตกงานออกเป็น Task เล็ก ๆ สำหรับคนที่ไม่เคยเขียนโค้ด

เรียงลำดับตั้งแต่:
1. สร้าง Project
2. สร้างหน้าเว็บ
3. เพิ่มแต่ละ Section
4. ปรับ Responsive
5. ตรวจสอบเว็บไซต์
6. เตรียม Git
7. Deploy Vercel

แต่ละ Task ต้องมี:
- ชื่องาน
- สิ่งที่ต้องทำ
- ผลลัพธ์ที่ต้องเห็น
- เงื่อนไขว่าเมื่อไรถือว่าเสร็จ

อย่าเขียนโค้ดตอนนี้

อ่าน PROJECT_CONTEXT.md ก่อน

ชื่อธุรกิจ: [เพิ่มยอดให้น่าเชื่อถือ]

กลุ่มลูกค้า: [ทุกเพศทุกวัย]

Requirements:
- สร้างโครงสร้าง Project ที่เหมาะสม
- สร้าง Landing Page หน้าเดียว
- มี Hero Section
- มี Services / Features
- มี Why Choose Us
- มี CTA
- มี Footer
- Responsive สำหรับ Desktop และ Mobile
- ใช้ภาษาไทย
- Design สะอาด ทันสมัย และเป็นมืออาชีพ
- ใช้ Content จริงจากข้อมูลธุรกิจ ไม่ใช้ Lorem Ipsum
- อย่าเพิ่มระบบที่ไม่จำเป็น

หลังจากสร้างเสร็จ:
1. ตรวจสอบว่ารันได้
2. บอกคำสั่งที่ใช้เปิด Development Server
3. อย่าหยุดกลางทางโดยไม่จำเป็น
